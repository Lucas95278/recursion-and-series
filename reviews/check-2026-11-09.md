### P1-02：中文将幂等性误说成额外贡献 E 为零的理由

位置：中文 351–357。

定义

```text
U = Σ_v b(v)
E = Σ_v (m(v)−1)·b(v)
V(r) = U + E
```

这个加法恒等式在所述前提下成立。但“E 也可能为零，例如加法幂等时”的解释不准确：**幂等性保证重复贡献可被吸收，不保证 E 本身为零。**

反例：在布尔或幺半群 `({False, True}, OR, False)` 中，取菱形图，四个节点贡献都为 True，路径重数为 `[1,1,1,2]`，则

```text
U = True
E = True
V(r) = True = U OR E
```

这里零元为 False，E 并非零。无权汇总与加权汇总却相等。

建议改为：“E 可能为零；也可能 E 不为零而 U+E=U。例如加法幂等时，根可达使所有 m(v)≥1，故 V(r)=U，但 E 未必为零。一般幺半群中只陈述加法恒等式。”同段末句“两者相差的是 E”也应删除或限定在具有减法的模型内。

### P1-03：两版都把递归到循环的一般转换误写成必须依赖重排公理

位置：中文 109、182–184；英文 106、173–175。

命题 1 可以证明某些重排保值，但递归改循环不一定重排。一个保持原运算嵌套次序的反例：

```python
def recursive(xs):
    return 0 if not xs else xs[0] - recursive(xs[1:])

def iterative(xs):
    result = 0
    for x in reversed(xs):
        result = x - result
    return result
```

两者在 `[3,2,1]` 上都为 2；减法既不结合也不交换。这里迭代按原递归返回的次序执行，未作代数重排。更一般的递归也可用显式栈保存待完成操作。

另外，§3.6 的 g 与 h 本来就按相同顺序更新累加器，并不是“三种顺序”；更换运算后它们仍可保持一致，不能说三种写法都会分道扬镳。“在非交换运算上，max 之外的操作多数不允许重排”也没有清晰含义；max 本身是交换运算。

建议把整段限定为：“这里展示的特定右嵌套到左累加变换会改变括号；整数加法的结合律足以处理本例的重新加括号。若还改变项序，需要另查交换性等条件。保持原嵌套次序的循环或显式栈模拟，不需要这些重排公理。”不要把某种转换的方法扩大为所有递归与循环之间的等价条件。

### P1-04：命题的充分条件在结论里又被写成了一般损失定律

位置：中文 212、290–292、482；英文 201、288–290、472。

有两类需要区分的问题：

1. **交换加法不要求固定遍历方向。** 精确交换幺半群上的节点和只依赖权值多重集，改变遍历次序也保值。固定根左右先序是命题 2 在一般非交换幺半群中的保证，不能混写成加法求和必须满足的条件。
2. **非交换不意味着每次改变项序都改变结果。** 例如字符串连接的载体不交换，但将 `['a','aa']` 改成 `['aa','a']` 后仍得到 `'aaa'`。应写“可能改变，通常无法保证不变”。一般幺半群下，形状无关要求保持具体先序权值列表；只说同一种遍历策略与同一多重集并不够，`rab` 与 `rba` 都可以来自根左右先序。

结论“一旦离开命题 1 条件，丢掉的就是顺序、括号或重数”也不能由三个充分性命题推出。不满足命题 1 不代表发生了某种必然的信息损失。例如在非交换幺半群里，可保序写出 `a_n ⊗ … ⊗ a_1 ⊗ c`，不存在必须丢弃顺序的问题。

建议将总结改为：“本文考察的几种表示或汇总变换，分别涉及项序、括号和贡献重数；是否保值需根据具体变换及合并运算判断。”分类表是选定实例的讨论清单，不是所有递归变换的完备分类。

## 4. 后续研究的数学核查

### 单链仿射研究

逐项复核了以下内容，未发现实质错误：

- `F(n)=A(n,r)+B(n,r)F(n−r)` 的展开公式及 r=0、r=n 的边界。
- 替代前沿后的精确误差 `B(n,r)(F(n−r)−t)`。
- 负系数下区间端点的翻转；仅知区间时取中点的最坏绝对误差最优性。
- 在没有前沿约束、剩余系数非零的信息模型中，不存在统一有限绝对误差界。
- 统一收缩假设下的前沿界与 `q^r M` 停止条件。
- 零系数屏蔽、负系数振荡及大于 1 的系数例子。
- `n=2r, a_k=2^k, b_k=1/2` 的反例：残项趋于 4/3，而非零。
- 无限链中残项消失的边界条件；有界解唯一性；`x_j=C·2^j` 的无界解反例。

“无前沿约束时不可能认证误差”的结论针对只给定已展开部分的信息模型，不能误读为一个已给定全部输入、基例的有限递推本身没有确定值。原文大体已表达这一限制，可再强调。

### 加权分支研究

逐项复核了按边路径展开、前沿误差界、共享节点合并系数、更紧界的信息模型、满二叉树反例、出边绝对系数和收缩，以及无限局部有限图的有界解唯一性。主要论证成立。

特别需要保留的限制是：

- 同节点路径系数抵消要求共用同一前沿近似；不能任意假设不同节点误差抵消。
- 每条边绝对值小于 1 不足以克服路径数增长。
- A 和 q 是已认证的先验界；若需要完整扫描图才能获得，不能自动宣称省计算。
- 无限情形限定有界解，且误差认证不等于程序能直接求出精确解。

额外用一张四节点有理数加权 DAG 做了独立逐路径枚举：含平行边、负系数，且同节点在深度 1 和 2 均出现。深度 0–4 的精确恒等式，以及合并有符号系数与绝对路径权重向量，均与原脚本结果一致。此检查补充现有穷举中未覆盖的结构组合，仍非一般证明。

### 研究内容的下一步定位

两份后续研究把问题从“能否改写为和”推进到“展开到哪里可以带误差保证地停止”，主线更具体。可以考虑围绕“残项传播与可认证截断”组织下一稿，而非持续扩写“递归的本质”。这是一项选题建议，不是已经完成的新颖性结论。

有限图部分还可以自行推导成统一矩阵形式：令 C_uv 为 u→v 所有平行边系数之和，取列向量 F、a，则

```text
F = a + CF
F = Σ_{j=0}^{d−1} C^j a + C^d F
```

按拓扑编号的有限 DAG 上 C 为严格上三角矩阵，因此幂零；`C^d` 的元素是长度 d 路径的有符号权重和。出边绝对系数和上界又给出无穷范数下的收缩估计。这说明其结果与线性系统、路径展开及收缩方法自然相连；**本轮未进行足以判定原创性的系统检索，不能将这些基本公式宣称为新发现。**
