## 2026-11-10：从展开公式走向误差认证

本轮形成两条主线：

1. **怎样安全地选择展开位置和层数？** 证明可变行长度收缩证书及单位成本进度界，同时给出最大原始系数贪心发散的幂零反例。
2. **是否必须整个系统都稳定？** 不必。只针对固定根与源项，可用有限可核验的标量递推证书保留根能看见的稳定模式；精确共享关系与数值近似必须区别。
