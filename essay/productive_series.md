# §7 支持材料：流展开、有限部分和与收敛

标签 [proved] 表示给定假设下的数学推导，[example] 表示实例，[literature] 表示既有概念且最终引用由文献清单统一补齐。本节不主张新颖性。

## 7.1 从状态展开流 [literature]

设 A 为项的集合，S 为状态集合，给定总函数 γ:S→A×S。对初态 s₀，递推定义 (aₙ,sₙ₊₁)=γ(sₙ)。在集合上的流模型 A^ℕ 中，定义

ana(γ)(s₀)=(a₀,a₁,a₂,…)。

它满足 out(ana(γ)(s))=(a,ana(γ)(s′))，其中 γ(s)=(a,s′)，out 将流分成首项和尾流。这是函子 F(X)=A×X 的流展开（anamorphism）；这里不涉及任意函子的推广。

[proved] 存在性由有限次迭代定义每个坐标给出；唯一性由对坐标 n 归纳得到：任何满足该方程的流映射都有相同首项和逐次相同的后续坐标。

程序中的 productivity 在本节指：对每个自然数 N，从初态计算并取得前 N 项都在有限步骤内完成。它要求每次所需状态转移及项计算可执行且终止；抽象总函数本身不自动保证给定程序具有这种性质。不要求各项耗时有统一上界，也不要求把整个无限流一次性存入内存。

## 7.2 部分和与有限递归严格对齐 [proved]

令 aₙ∈ℚ（也可在精确实数数学模型中讨论），定义 P₀=0，Pₙ₊₁=Pₙ+aₙ。因此 P_N=Σ_{k=0}^{N-1}a_k。可用扩展状态 (s,p) 同时产生项与部分和：若 γ(s)=(a,s′)，令 Γ(s,p)=((a,p+a),(s′,p+a))。从 (s₀,0) 展开得到 (a₀,P₁),(a₁,P₂),…。

对有限前缀另定义返回值递归 R(0)=0，R(N+1)=R(N)+a_N。由 N 归纳立即得到 R(N)=P_N。此处 R 的加法方向与累加器一致；若改为 a_N+R(N)，在本节的有理数加法上仍相等。该对齐只比较有限返回值，不把无限过程当成一个会最终返回的普通递归调用。

代码中递归版本在到达基例后依次索取流项，使 a₀,…,a_{N-1} 与上述公式逐一对应；它只用于小 N 的演示，受 Python 递归深度限制。

## 7.3 可求精确误差的实例 [proved] [example]

取 S=ℕ，γ(n)=(2^{-(n+1)},n+1)。则 aₙ=2^{-(n+1)}，P_N=1-2^{-N}，N≥0。证明：N=0 时两边为零；若成立，加上 2^{-(N+1)} 即得 P_{N+1}=1-2^{-(N+1)}。又 2^{-N}→0，故级数收敛到 1，误差为 1-P_N=2^{-N}。

这次能谈误差，是因为已证明极限及其与部分和之差；误差是该级数的尾和，不是仅凭递归外形得到的拉格朗日余项。程序使用 Fraction 精确产生前缀，避免把浮点舍入与数学收敛混在一起。

## 7.4 三个不能混同的判断

[example] 常数项流 1,1,… 是 productive，其部分和 P_N=N 无有限实数极限。

[example] 交替项流 1,-1,1,-1,… 是 productive，其部分和 1,0,1,0,… 不收敛。

[proved] 因此，前缀可计算不蕴含部分和收敛。本节几何级数的收敛来自独立证明，不能由流生成器会产出下一项推出。

无穷过程的生产性、部分和的数学极限、有限精度程序的误差控制是三个不同问题。本节只建立状态展开与有限递归部分和的对应，不主张解决共归纳的一般问题，也不把所有无限递归解释为级数。

## 复现

仓库根目录运行 `python3 essay/productive_series_checks.py`。脚本检验 N=0,…,20 的精确几何部分和、递归返回值及误差，并打印两个 productive 但部分和不收敛的流的有限前缀。有限输出不能证明一般 productivity 或收敛，证明见上文。
